# Privacy-Safe Image Policy — ACaring Adult Home Website

_Last updated: 2026-05-30_

## Purpose

Images on the website should communicate warmth, safety, home life, and trust without exposing resident identity or sensitive information.

Because this is an Adult Family Home website, images must be chosen carefully.

## Default rule

Do not publish identifiable resident images unless the business has reviewed and approved written authorization from the resident or legally authorized representative.

When uncertain, do not use the image.

## Preferred image types

| Image type | Safe use |
|---|---|
| Exterior home photo | Good if address/public location is approved |
| Front door / walkway | Good if no residents shown |
| Kitchen table setup | Good if staged and no personal items |
| Meal plate / dining setup | Good if no resident faces or medication visible |
| Living room seating | Good if staged and tidy |
| Activity table | Good if no names, faces, or personal records |
| Garden / flowers / outdoor seating | Good trust-building image |
| Staff-only photo | Use only with staff permission |
| Hands-only activity photo | Use carefully; avoid identifying details |
| Abstract warm home detail | Good fallback |

## Images to avoid

Avoid images that show:

- Resident faces
- Resident names
- Medication bottles or pill organizers
- Medical charts
- Care plans
- Whiteboards with resident information
- Mail, forms, IDs, insurance cards, or documents
- Bathroom/private personal care scenes
- Bedroom scenes with personal resident belongings
- Anything that implies a diagnosis or condition of a specific resident

## Earlier placeholder image names

The following placeholder names were discussed previously:

- `kitchen-table.jpg`
- `morning-care.jpg`
- `meals.jpg`
- `activity.jpg`
- `evening-routine.jpg`

Recommended interpretation:

| Placeholder | Safer image direction |
|---|---|
| `kitchen-table.jpg` | Empty or staged dining table, warm light, no people required |
| `morning-care.jpg` | Avoid personal care scene; use morning sunlight, coffee/tea, tidy hallway, or prepared breakfast table |
| `meals.jpg` | Plate of food or dining setup, no residents, no medication |
| `activity.jpg` | Puzzle, cards, crafts, flowers, books on table; no names or faces |
| `evening-routine.jpg` | Lamp, blanket, calm seating area, hallway lighting, no residents in bedroom/personal care setting |

## Alt text rules

Alt text should describe the image without adding unsupported claims.

Good:

```text
A warm dining table prepared for a home-style meal.
```

Avoid:

```text
Residents with dementia receiving loving care at ACaring Adult Home.
```

## File naming rules

Use descriptive names:

- `dining-table-prepared.jpg`
- `front-entry-walkway.jpg`
- `living-room-seating.jpg`
- `garden-seating-area.jpg`
- `activity-table-puzzle.jpg`
- `evening-lamp-living-room.jpg`

Avoid names containing resident names or sensitive details.

## Codex rules

When Codex touches images:

- Do not invent image files that do not exist.
- If a referenced image is missing, either remove the reference or replace it with an existing approved image.
- Add useful `alt` text.
- Do not add stock images with unrealistic institutional scenes.
- Update `DEV_LOG.md` with image changes.
