# ACaring Adult Home Website — Codex Documentation Pack

_Last updated: 2026-05-30_

This `docs/` folder is intended to be copied into the root of the ACaring Adult Home website repository and used as the working context for Codex.

The purpose is to help Codex make controlled, practical improvements to the website without losing the current calm, trust-building direction of the site.

## Current website direction

The website is a small, multi-page Adult Family Home website for ACaring Adult Home, serving families, placement/referral partners, and prospective residents in the Federal Way, Washington area.

Known page structure from the prior website setup:

- `index.html` — Home
- `about.html` — About the home
- `care-services.html` — Care services
- `who-we-serve.html` — Resident fit / who the home serves
- `daily-life.html` — Daily life and care rhythm
- `events.html` — Events / activities
- `referrals.html` — Referral pathway
- `contact.html` — Contact / inquiry page
- `styles.css` — Shared styling
- `script.js` — Shared behavior
- `README.txt` — Original basic project notes

## How to use this folder with Codex

When opening a Codex session, start with this instruction:

```text
Read the docs/ folder first. Use docs/CODEX_INSTRUCTIONS.md as the controlling development guide. Do not modify application code until you have summarized the current state and the specific files you intend to change. Preserve the current calm Adult Family Home tone and static-site structure unless a document explicitly says otherwise.
```

## Recommended Codex workflow

1. Ask Codex to read `docs/PROJECT_STATE.md`, `docs/ROADMAP.md`, and `docs/CODEX_INSTRUCTIONS.md`.
2. Ask Codex to inspect the current repository.
3. Ask Codex to update `docs/DEV_LOG.md` with what it finds.
4. Give Codex one focused task at a time.
5. Require Codex to update `docs/DECISIONS.md` whenever it makes a structural choice.
6. Require Codex to run through `docs/TESTING_CHECKLIST.md` before completing work.

## Important principle

This is not just a brochure site. The site should gradually become a practical referral and trust-building system:

- Easy for families to contact the home
- Easy for referral partners to understand fit
- Clear about services without overpromising
- Privacy-safe and resident-respectful
- Able to support upcoming events, activities, resources, and future referral outreach
